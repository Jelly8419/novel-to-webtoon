# API·서버 규칙

- 요청 입력은 Zod로 검증한다. 검증 실패는 400과 사용자에게 보여줄 한국어 메시지로 응답한다.
- 로그인 사용자 본인의 작품만 읽고 쓸 수 있게 모든 조회에 사용자 ID 조건을 건다.
- 게스트는 읽기 전용(샘플 작품). 생성·수정 API는 401.
- 생성 요청은 사용자별 하루 횟수 제한을 건다(비용 방어).
- 컷 생성처럼 오래 걸리는 작업은 요청 안에서 끝까지 기다리지 않는다. 작업을 등록하고 상태를 조회하는 방식으로 만든다(Vercel 함수 실행 시간 제한).
- 에러는 서버 로그에 원인을 남기고, 사용자에게는 짧은 안내만 보여준다. 스택이나 API 키가 응답에 섞이지 않게 한다.
