# 화면(UI) 규칙

- 화면 설계는 와이어프레임 7개 화면을 기준으로 한다: 시작·로그인, 내 작품 목록, 새 작품 만들기, 작품 상세, 캐릭터 컨펌, 생성 진행, 웹툰 뷰어. 목록과 흐름은 `docs/overview.md`.
- 기본은 서버 컴포넌트. 상태·이벤트가 필요한 부분만 `"use client"` 로 분리한다.
- 스타일은 Tailwind 유틸리티 클래스. 색은 무채색 위주, 강조는 한 가지만.
- 접근성: 클릭되는 것은 `<button>` 또는 `<a>`, 입력은 `<label>` 과 연결, 아이콘만 있는 버튼엔 `aria-label`. 터치 영역 최소 44px.
- 문구는 한국어 해요체. 저작권 고지(권리 확인 체크, 기본 비공개)를 빼지 않는다.
- 게스트 모드에서는 생성 기능을 막고 샘플 작품만 보여준다.
- 긴 작업(컷 생성)은 진행 상태를 단계별로 보여주고, 완성된 컷부터 먼저 보이게 한다.
