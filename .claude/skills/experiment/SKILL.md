# AI 실험

주제: $ARGUMENTS

1. **설계를 먼저 보여주고 승인받는다**
   - 가설: 무엇을 확인하려는지
   - 비교군: 모델·프롬프트·설정 조합 (2~3개)
   - 입력: 같은 테스트 텍스트와 같은 시드로 공정하게 비교
   - 예상 비용: 호출 수 × 장당 가격. 실제 API(`AI_MODE=live`)를 쓰므로 사용자 허락 필수
   - 평가 기준: 예) 캐릭터 얼굴·옷 일치, 장면 묘사 반영, 그림체 일관성
2. `exp/<주제>` 브랜치에서 `scripts/experiments/` 아래 일회성 스크립트로 실행한다. 결과 이미지는 `experiments/<날짜>-<주제>/` 에 저장하고, 이 폴더는 커밋하지 않는다(.gitignore).
3. 결과를 표로 정리한다: 비교군별 대표 이미지, 평가, 장당 비용, 생성 시간.
4. 노션 "실험 기록"(`docs/notion.md`) 페이지에 템플릿 형식(가설, 설정, 결과, 비용·속도, 결론)으로 추가하고, 대표 비교 이미지는 사용자에게 업로드를 요청한다.
5. 결론이 파이프라인 방향을 바꾸면 `/decision` 으로 이어서 기록할지 묻는다.
