# 트러블슈팅 기록

문제: $ARGUMENTS

1. 이번 대화와 커밋 기록에서 다음을 정리한다. 확인되지 않은 원인은 추측이라고 표시한다.
   - 증상: 에러 메시지 원문(비밀값 제거), 재현 방법
   - 원인
   - 시도한 방법: 안 됐던 것 포함, 왜 안 됐는지
   - 해결: 최종 수정과 관련 커밋/PR
   - 배운 점: 다음에 같은 문제를 빨리 알아볼 신호
2. 초안을 사용자에게 보여주고 확인받는다.
3. 노션 "트러블슈팅"(`docs/notion.md`) 페이지 끝에 토글 형식으로 추가한다.
4. 재발 방지에 규칙이 필요하면 `CLAUDE.md` 또는 `.claude/rules/` 에 한 줄 추가를 제안한다.
