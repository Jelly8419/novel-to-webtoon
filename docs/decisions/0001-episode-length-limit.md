# 0001. 입력 분량을 화당 2,000자로 제한

- 날짜: 2026-10-22
- 상태: 확정
- 분류: 범위

## 배경

소설 한 권(해리포터 1권 기준 원서 약 7만 7천 단어)을 그대로 만화로 옮기면 수백~수천 컷이 되어 생성 비용과 시간이 감당되지 않는다.

## 결정

한 번에 처리하는 단위를 "화"로 하고, 화당 텍스트를 최대 2,000자로 제한한다.

## 이유

1인 포트폴리오에서는 규모보다 끝까지 동작하는 완성도가 중요하다. 짧은 단위로 제한해야 비용·속도·품질을 통제할 수 있다.

## 검토한 대안

- 소설 전체 변환: 비용·시간 과다
- 챕터 단위 변환: 챕터 길이 편차가 커서 컷 수 예측이 어려움

## 영향

`LIMITS.maxEpisodeChars = 2000`. 업로드 화면에 글자 수 안내.
