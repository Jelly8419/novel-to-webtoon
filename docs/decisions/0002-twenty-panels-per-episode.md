# 0002. 화당 컷 수를 20컷 내외로

- 날짜: 2026-10-22
- 상태: 확정
- 분류: 범위

## 배경

처음엔 8컷으로 잡았으나, 일반 웹툰 1화는 50~70컷이라 8컷은 웹툰보다 4컷 만화에 가깝다.

## 결정

목표 20컷, 최대 24컷. 텍스트 약 100자당 1컷 비율.

## 이유

2,000자 입력과 비율이 맞고, 웹툰다운 연출이 가능하면서 비용·생성 시간이 감당 가능한 수준이다.

## 검토한 대안

- 4컷 / 8컷: 웹툰 느낌이 나지 않음
- 50~60컷(일반 웹툰 1화): 비용·시간·일관성 부담이 커서 MVP 이후 확장 목표로 보류

## 영향

`LIMITS.targetPanels = 20`, `LIMITS.maxPanels = 24`. 생성 진행 화면은 완성된 컷부터 먼저 보여준다.
