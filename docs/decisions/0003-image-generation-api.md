# 0003. 작화는 저가 이미지 생성 API(FLUX 계열)로

- 날짜: 2026-10-22
- 상태: 확정
- 분류: 기술

## 배경

RTX 3060에서 ComfyUI로 로컬 생성하는 안을 검토했으나, 로컬 GPU는 컴퓨터가 켜져 있어야 해서 배포된 서비스에서 쓸 수 없다.

## 결정

오픈 모델을 API로 제공하는 서비스의 FLUX 계열 모델을 쓴다. 개발 검증은 FLUX.1 schnell, 최종 작화 모델은 캐릭터 일관성 실험 후 결정한다.

## 이유

2026-10 기준 DeepInfra 가격으로 schnell은 1024×1024 장당 약 $0.002(4스텝), 20컷 1화 약 60원. 서버에 GPU 없이 운영할 수 있다.

## 검토한 대안

- 로컬 GPU + ComfyUI: 비용은 거의 0이지만 배포 서비스에 부적합
- 상용 고급 이미지 API: 장당 수십~백몇십 원으로 20컷 기준 부담이 큼

## 영향

`src/lib/ai` 의 이미지 클라이언트는 레퍼런스 이미지 입력을 지원하는 구조로 만든다. 모델별 상업 이용 라이선스를 확인해야 한다.
