# 0004. 카카오 로그인 + 게스트 둘러보기

- 날짜: 2026-10-22
- 상태: 확정
- 분류: UX

## 배경

작품·그림체·캐릭터 시트를 사용자별로 저장해야 하므로 로그인이 필요하다. 한편 채용 담당자는 로그인까지 하며 써보지 않는 경우가 많다.

## 결정

카카오 로그인(Auth.js)과, 로그인 없이 샘플 작품만 볼 수 있는 게스트 모드를 함께 제공한다.

## 이유

국내 사용자에게 익숙한 로그인이고, 게스트 모드로 포트폴리오 열람 장벽을 없앤다.

## 검토한 대안

- 회원가입 없이 운영: 작품 이어 그리기를 사용자별로 저장할 수 없음
- 이메일 가입: 가입 장벽이 높음

## 영향

게스트는 읽기 전용(생성 API 401). 카카오 디벨로퍼스 앱 등록 필요.
