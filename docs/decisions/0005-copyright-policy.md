# 0005. 저작권: 권리 확인 + 비공개 기본값 + 신고·삭제 절차

- 날짜: 2026-10-22
- 상태: 확정
- 분류: 정책

## 배경

업로드 단계에서 글의 저작권 여부를 완벽하게 가려낼 방법이 없다.

## 결정

업로드 시 권리 확인 체크를 필수로 받고, 생성물은 기본 비공개로 두며, 권리자 신고 시 즉시 비공개 처리하는 절차를 둔다. 데모 소재는 직접 쓴 글이나 저작권 만료 작품만 쓴다.

## 이유

면책 고지만으로는 부족하고, 고지와 실제 대응 절차가 함께 있어야 한다. (실서비스 전 법률 전문가 검토 필요)

## 검토한 대안

- 면책 고지만 표시: 침해를 알고도 방치하면 책임이 생길 수 있음
- 자동 필터로 사전 차단: 정확도 한계, 향후 과제로 보류

## 영향

새 작품 화면의 권리 확인 체크, 뷰어의 공개 설정 기본값 "나만 보기". BM 2단계(작가 게시·판매)는 작가 인증 후에만.
