# 0007. Claude Code 하네스 기반 1인 개발 워크플로우

- 날짜: 2026-10-22
- 상태: 확정
- 분류: 기술

## 배경

기획부터 배포까지 혼자 진행하면서 AI 코딩 에이전트를 적극 활용한다. 규칙 없이 대화로만 쓰면 결과 품질과 일관성이 들쭉날쭉하다.

## 결정

에이전트가 같은 규칙으로 일하고 스스로 검증하도록 하네스를 구축한다.

- 컨텍스트: `CLAUDE.md`, `.claude/rules/`, `docs/`
- 가드레일: 권한 설정, 비밀값·위험 명령 차단 훅, AI 기본값 mock
- 검증: 저장 시 포맷·린트 훅, 종료 시 타입체크·테스트 훅, CI
- 자동화: `/feature`, `/decision`, `/experiment`, `/troubleshoot`, `reviewer`·`storyboard-judge` 에이전트
- 연결: Notion MCP(작업·기록), Playwright MCP(화면 확인)

## 이유

1인 개발의 속도와 품질을 함께 확보하고, 결정·실험·문제 해결 기록이 자동으로 쌓인다. 하네스 설계 자체도 포트폴리오 어필 포인트다.

## 검토한 대안

- 규칙 없이 대화형 AI 코딩: 품질 편차, 기록 누락
- AI 없이 직접 개발: 6주 일정 안에 범위를 소화하기 어려움

## 영향

모든 기능 작업은 `/feature` 루프를 따른다. 상세는 노션 "개발 하네스 & 워크플로우" 페이지.
