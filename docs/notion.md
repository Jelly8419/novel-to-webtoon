# 노션 연결 정보

진행 관리와 기록은 노션 "소설→웹툰 변환 서비스 프로젝트" 페이지에서 한다. 커맨드(`/feature`, `/decision`, `/experiment`, `/troubleshoot`)는 Notion MCP로 아래 위치를 읽고 쓴다.
노션 MCP가 연결되지 않았으면 기록할 내용을 마크다운으로 정리해 사용자에게 보여주고, 붙여 넣어 달라고 요청한다.

## 데이터베이스 속성

- **작업 일정**: 작업(제목), 상태(할 일 / 진행 중 / 완료), 단계(기획 / 파이프라인 검증 / 화면 제작 / 마무리), 주차(1주차~6주차), 마감일, 메모
- **의사결정 로그**: 결정(제목), 날짜, 분류(범위 / 기술 / 비용 / 정책 / UX), 이유, 검토한 대안

ID는 접근 권한이 있는 계정에서만 의미가 있으며 비밀값이 아니다.
