# 서비스 개요

소설 텍스트 파일을 올리면 AI가 웹툰으로 그려주고, 같은 작품의 다음 화도 같은 그림체와 캐릭터로 이어서 그려주는 서비스. 원본 기획서는 노션 "기획서" 페이지(`docs/notion.md`).

- **한 줄 소개**: 읽기 대신 보는 소설, 화 단위로 이어지는 나만의 웹툰
- **타깃**: 누구나, 특히 긴 글을 읽기 부담스러워하는 사람
- **핵심 차별점**: 작품 단위로 그림체와 캐릭터 시트를 저장해 다음 화에 재사용

## MVP 범위

| 항목   | 기준                                                    |
| ------ | ------------------------------------------------------- |
| 분량   | 화당 텍스트 최대 2,000자, 20컷 내외 (최대 24컷)         |
| 입력   | .txt, .md                                               |
| 그림체 | 프리셋 3종 + 자유 설명                                  |
| 로그인 | 카카오 로그인 + 게스트 둘러보기(샘플 작품만, 생성 불가) |
| AI     | 텍스트: LLM API, 작화: 저가 이미지 API(FLUX 계열)       |
| 제외   | 회원 간 공유, 결제, 모바일 앱                           |

일반 웹툰 1화 분량(50~60컷, 텍스트 5,000자)은 MVP 이후 확장 목표.

## 핵심 기능

1. **작품 관리**: 내 작품 목록, 이어서 그릴 작품 선택
2. **텍스트 업로드**: 화 단위 첨부, 업로드 시 권리 확인 체크
3. **그림체 설정**: 새 작품 생성 시 선택, 이후 고정
4. **캐릭터 컨펌**: 새 인물이 나오면 시안을 보여주고 승인 후 작화. 첫 화는 전원 컨펌
5. **화 생성**: 장면 분석 → 콘티 → 컷 작화 → 말풍선 조판
6. **컷 재생성, 다운로드** (권장)

## 화면 (와이어프레임 7개)

1. 시작·로그인 — 카카오로 시작하기, 게스트로 둘러보기, 샘플 작품
2. 내 작품 목록 — 게스트 안내 배너, 작품 카드, 새 작품
3. 새 작품 만들기 — 제목, 그림체, 1화 첨부, 권리 확인
4. 작품 상세 — 회차 목록, 등장인물 시트, 다음 화 이어 그리기
5. 캐릭터 컨펌 — 새 인물 시안, 외모 묘사 수정, 승인/다시 그리기
6. 생성 진행 — 단계별 상태, 완성된 컷 미리보기
7. 웹툰 뷰어 — 세로 스크롤, 컷별 다시 그리기, 다운로드, 공개 설정

## 저작권 정책

- 업로드 시 "본인 창작물이거나 이용 권한이 있음" 체크 필수
- 생성된 웹툰은 기본 비공개
- 권리자 신고 시 즉시 비공개 처리하는 창구
- 데모 소재는 직접 쓴 글이나 저작권 만료 작품만 사용
