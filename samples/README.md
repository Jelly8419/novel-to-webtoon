# 테스트용 원문

콘티·작화 실험에 쓰는 텍스트. 저작권 문제가 없도록 **직접 쓴 글이나 저작권이 만료된 작품만** 넣는다 (ADR 0005).

| 파일                 | 내용                                                                                               | 출처                          |
| -------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------- |
| `rainy-umbrella.txt` | 장마 첫날, 우산 하나를 같이 쓰는 두 고등학생. 약 1,300자(목표 13컷), 인물 2명, 장면 4개, 대사 다수 | 이 프로젝트를 위해 새로 쓴 글 |

실제 LLM으로 콘티 만들어 보기:

```bash
npm run try:storyboard -- samples/rainy-umbrella.txt          # mock (비용 0원)
npm run try:storyboard -- samples/rainy-umbrella.txt --live   # OpenAI 실제 호출 (.env.local 의 LLM_API_KEY)
```
